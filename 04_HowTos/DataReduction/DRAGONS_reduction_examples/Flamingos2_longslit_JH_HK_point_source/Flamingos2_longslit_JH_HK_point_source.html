Goals¶

Showcase how to reduce Flamingos-2 longslit data using the Gemini DRAGONS package on the Data Lab science platform using a custom DRAGONS kernel "DRAGONS-4.2.1 (DL,Py3.12)". The steps include downloading data from the Gemini archive, setting up a DRAGONS calibration service, processing flats, darks, a bad pixel mask, and science frames, and creating reduced spectra in the JH and HK bands.

The steps include downloading data from the Gemini archive, setting up a DRAGONS calibration service, updating file headers, processing flats, darks, tellurics, and science frames, and displaying the final reduced spectra.

Summary¶

DRAGONS is a Python-based astronomical data reduction platform written by the Gemini Science User Support Department. It can currently be used to reduce imaging data from Gemini instruments GMOS, NIRI, Flamingos 2, GSAOI, and GNIRS, as well as spectroscopic data taken with Flamingos 2, GNIRS, GHOST, and GMOS in longslit mode and GNIRS data taken in cross-dispersion mode. Linked here is a general list of guides, manuals, and tutorials about the use of DRAGONS.

In this notebook, we present an example of a DRAGONS Jupyter notebook to reduce example Gemini South Flamingos-2 JH and HK spectral data. This notebook will not present all of the details of the many options available to adjust or optimize the DRAGONS Flamingos-2 data reduction process; rather, it will just show one example of a standard reduction of a Flamingos-2 spectral dataset.

The data used in this notebook example is Flamingos-2 JH and HK spectra from the Gemini archive of the recurrent nova U Sco from the Gemini South program "The 2022 Eruption of the recurrent nova U Sco", PI: N. Evans, program ID GS-2022A-DD-105.

Prepare the working directory¶

If you have any intermediate files that were created from running this code in the past, you will need to remove them from your working directory. The cell below defines a clean-up function that will remove all the fits files from your working directory. This function will be called again at the end of the tutorial, leaving you with only the final product. By default, this function will delete all files in the working directory. If there are files that have been previously reduced that you would like to keep, set save_reduced=1 when calling the function.

def clean_up(save_reduced=0):
    #Does the calibrations directory already exist?
    caldb_Exist = os.path.exists('./calibrations') 
    
    if caldb_Exist:
        shutil.rmtree('./calibrations', ignore_errors=True)

    #Remove existing log and list files.
    work_dir_path = os.getcwd()
    work_dir = os.listdir(work_dir_path)

    for item in work_dir:
        if item.endswith(".log") or item.endswith(".list"):
            os.remove(os.path.join(work_dir_path, item))
    
    #Next, we will remove all the existing fits files, except for the previously reduced files, depending on what you set save_reduced to.
    if save_reduced:
        all_files_0 = glob.glob('*.fits')
        save = dataselect.select_data(all_files_0, [], ['PROCESSED'])
        
        for s in save:
            os.remove(os.path.join(work_dir_path,s))

    else:
        all_files_0 = glob.glob('*.fits')
        for a in all_files_0:
            os.remove(os.path.join(work_dir_path,a))

This data comes from a Flamingos-2 program that observed the recurrent nova U Sco. The 2-pixel slit is used with an ABBA-ABBA dither sequence.

Fix the header¶

As you can see from the output above, most sequences were not affected by this issue, but the HK science sequence was. Each frame was taken with a 25-second exposure time, but the last frame in the sequence shows an EXPTIME of 90.0 seconds, and LNRS is set to 1 instead of 4, as in the other frames. The values for the last frame belong to the next frame, which was actually a flat.

Fortunately, it is easy to update the header. To do so, we will create a copy of the file with the incorrect values, S20220617S0041.fits, and name it S20220617S0041_fixed.fits. Next, we will open the copied file with astrodata and manually redefine the EXPTIME and LNRS values. Once the updated file is created, we will delete the file with the issue and rename the new file to match the original.

All calibration and science files require a master dark that matches their exposure times. To accomplish this, we will need to create a master dark for each exposure time.

Create a master flat field¶

Flamingos-2 longslit flats are normally obtained at night along with the observation sequence to match the telescope and instrument flexure. Flamingos-2 longslit master flat fields are created from the lamp-on flats(s) and a master dark matching the flats exposure times. Lamp-off flats are not used. In Flamingos-2 spectroscopic observations, a blocking filter is used. The sharp drops in signal at both ends make fitting a function difficult. The recommendation is to set the region to be between the sharp drops and then fit a low-order cubic spline. This is not the same as what is recommended for the other Gemini spectrographs, where a high-order spline is recommended to fit all the wiggles.

For Flamingos-2, only the overall shape should be fit. The detailed fitting will be handled when the sensitivity function is calculated using the telluric star. Below are the appropriate defaults for the order and the region to use to normalize the flat for each grism and filter combination. When this cell is done running, the master flats will contain the suffix _flat.fits.

Processed Arc - Wavelength Solution¶

Obtaining the wavelength solution for Flamingos-2 is a straightforward process. There are usually a sufficient number of lines in the lamp. However, the lines become asymmetric as they move away from the center. To account for this, there are provisions in the algorithm to account for that effect, but the precision of the solution is limited.

The recipe for the arc requires a flat as it contains a map of the unilluminated areas. The master dark is required because of the strong pattern that is often horizontal and that could be interpreted as an emission line if not removed. This cell will produce four PDF files with the suffix _wavelengthSolutionDetermined.pdf and four fits files with the suffix _arc.fits.

Telluric Standards¶

Two telluric standards are required to reduce this data set. The HK observations were done at the beginning of the program's sequence. A HK telluric was observed before the start of the science sequence. The JH observations were done at the end of the sequence, and the matching JH telluric was obtained afterward.

The JH telluric is HIP 83920, an A0V star with an estimated temperature of 9700K and an H magnitude of 8.044. The HK telluric is HIP 79156, an A0.5V star with an estimated temperature of 9500K and an H magnitude of 7.576. (Temperatures from Eric Mamajek’s list “A Modern Mean Dwarf Stellar Color and Effective Temperature Sequence” https://www.pas.rochester.edu/~emamajek/EEM_dwarf_UBVIJHK_colors_Teff.txt) These physical characteristics are required to properly calculate and fit a telluric model to the star and scale the sensitivity function. They are fed to the primitive fitTelluric.

Note that Astrodata recognizes the data as normal Flamingos-2 long-slit science spectra. To calculate the telluric correction, we need to specify the telluric recipe (reduceTelluric), otherwise the default science reduction will be run.

Also note that for the HK observations, we call the prepare:bad_wcs option to account for the incorrect WCS data.

Running the following cell will produce two files whose names end in _telluric.fits.

Reduce the science¶

The target of this program is a recurrent nova, U Sco, that was going through an eruption at the time of the observations. The dither pattern is a standard ABBA, repeated once.

DRAGONS will subtract the dark current, flatfield the data, apply the wavelength calibration, subtract the sky, and stack the aligned spectra. Then the source will be extracted into a 1D spectrum, the telluric features removed, and the spectrum flux-calibrated.

Following the wavelength calibration, the default recipe has an optional step to adjust the wavelength zero point using the sky lines. By default, this step will NOT make any adjustment. The DRAGONS team found that in general, the adjustment is so small as to be in the noise. If you wish to make an adjustment or try it out, see Adjusting the Wavelength Zeropoint to learn how.

When the following cell is done running, each band will have a file ending in _1D.fits and _2D.fits. Since extractSpectra and telluricCorrect are called, two _telluricCorrected.fits files and two _extracted.fits files will also be created.

 def plotter(file,adjust_y_lim=None):
    """Plot reduced spectra.
    
    Parameters
    ----------
    file : string
        Name of the file that will be plotted.
    adjust_y_lim : tuple (optional)
        A tuple containing the desired min and max value for the y-axis. 
    
    Examples
    --------
    If you want to use the default y-limits:
         plotter('N20170113S0146_ordersCombined.fits')

    If you want to adjust the y-limits:
        plotter('N20170113S0146_ordersCombined.fits',adjust_y_lim=(0,1e-17))
    """
    #Open the file with astrodata
    ad = astrodata.open(file)

    #Loop over all of the orders
    #for j in range(0,len(ad)):
    data = ad[0].data
    wavelength = ad[0].wcs(np.arange(data.size)).astype(np.float32)
    units = ad[0].wcs.output_frame.unit[0]

    #Some observations contain noisy data that can be masked out. 
    #The mask information is stored as an extension.
    mask = ad[0].mask

    #Create a filter that will leave out the noisy data.
    is_good = (mask == 0)
    clean_wave = wavelength[is_good]
    clean_data = data[is_good]

    plt.xlabel(f'Wavelength ({units})')
    plt.ylabel(f'Signal ({ad[0].hdr["BUNIT"]})')
    
    plt.plot(clean_wave, clean_data, lw=1.)

    if adjust_y_lim:
        plt.ylim(adjust_y_lim)
        
    plt.title(f'{file} - Aperture 1')
    plt.show()
