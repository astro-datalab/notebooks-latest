Goals & Summary¶

SPARCL (SPectra Analysis and Retrievable Catalog Lab) is an online service for discovery and retrieval of one-dimensional optical-infrared spectra (Juneau et al. 2025). SPARCL is designed to work for large survey datasets containing many millions of spectra, and to provide access to multiple different data sets through common methods. For more information, see the SPARCL User Guide.

This notebook provides a basic introduction to using the SPARCL client (or sparclclient) to find and retrieve spectroscopic data within a Python notebook context. The sparclclient connects to the SPARCL server at NSF NOIRLab and provides access to the contents of the SPARCL database.

To see the current data sets and number of spectra available in the SPARCL database, please visit the SPARCL summary page.

To get the latest sparclclient documentation, visit the sparclclient readthedocs site.

Feedback on SPARCL (questions, comments, science use cases, feature requests, bug reports, confusing error messages, etc.) can be submitted to datalab-spectro@noirlab.edu. For bug reports and confusing error messages, it's helpful if you include: a log of what you did, the result you got, and the result you expected.

Retrieve records by sparcl_id using client.retrieve()¶

In order to retrieve spectra records from SPARCL by sparcl_id, pass the following to the client.retrieve() method:

uuid_list : List of SPARCL IDs.
dataset_list : List of data sets to search for the SPARCL IDs in (default: None, which will search all available data sets).
include : List of field names to include in each record (default: 'DEFAULT').
limit : Maximum number of records to return (default: 500). Max allowed is 24,000.
units : Set to True to include units in the header for each applicable field (default: True).
fmt : Output format for the results. If 'specutils', the results are automatically converted to the most appropriate specutils object (either a Spectrum, SpectrumList, or SpectrumCollection) depending on the data. If 'pandas', the results are automatically converted to a Pandas Dataframe object (default: None, which returns a sparcl.Results.Retrieved object).

NOTE: A reasonable number of records to request retrieval of is about 10,000. Exceeding this value may cause the retrieval to timeout or fail.

specutils¶

Both client.retrieve() and client.retrieve_by_specid() can accept a fmt='specutils' argument that automatically converts results into the most appropriate specutils object, with units read directly from the SPARCL response header.

Depending on the wavelength grids of the retrieved spectra, the return type will be:

Condition Return type
All records share the same wavelength grid Spectrum
Different wavelength array lengths SpectrumList
Same wavelength array length, different pixel values SpectrumCollection

fmt='specutils' requires units=True (the default) in the retrieve call. If units=False is passed, conversion will raise a ValueError.

NOTE: For performance reasons, records returned by client.retrieve() are not guaranteed to match the order of the input IDs. If you plan to convert results into specutils or Pandas objects and need to preserve order: first call client.retrieve() without setting fmt to obtain raw records, then use the reorder() method to align the results with the input ID order, and finally convert the reordered records using to_specutils() or to_pandas(). See Appendix B for examples.

Retrieve records by specid using client.retrieve_by_specid()¶

In order to retrieve spectra records from SPARCL by specid, pass the following to the client.retrieve_by_specid() method:

specid_list : List of specIDs.
dataset_list : List of data sets to search for the specIDs in (default: None, which will search all available data sets).
include : List of field names to include in each record (default: 'DEFAULT').
limit : Maximum number of records to return (default: 500). Max allowed is 24,000.
units : Set to True to include units in the header for each applicable field (default: True).
fmt : Output format for the results. If 'specutils', the results are automatically converted to the most appropriate specutils object (either a Spectrum, SpectrumList, or SpectrumCollection) depending on the data. If 'pandas', the results are automatically converted to a Pandas Dataframe object (default: None, which returns a sparcl.Results.Retrieved object).

NOTE: A reasonable number of records to request retrieval of is about 10,000. Exceeding this value may cause the retrieval to timeout or fail.

def plot_spec(index, results):
    """
    Pass an index value and the output from using client.retrieve()
    to plot the spectrum at the specified index.
    """
    
    record = results.records[index]

    sparcl_id = record.sparcl_id
    data_release = record.data_release
    flux = record.flux
    wavelength = record.wavelength
    model = record.model
    spectype = record.spectype
    redshift = record.redshift
    ra = record.ra
    dec = record.dec

    plt.title(f"Data Set = {data_release}\n"
              f"Type = {spectype}\n"
              f"ID = {sparcl_id}\n"
              f"Redshift = {redshift}\n"
              f"RA = {ra}\n"
              f"Dec = {dec}", loc='left')
    plt.xlabel('$\lambda\ [\AA]$')
    plt.ylabel('$f_{\lambda}$ $(10^{-17}$ $erg$ $s^{-1}$ $cm^{-2}$ $\AA^{-1})$')
    
    # Plot unsmoothed spectrum in grey
    plt.plot(wavelength, flux, color='k', alpha=0.2, label='Unsmoothed spectrum')
    
    # Overplot spectrum smoothed using a 1-D Gaussian Kernel in black
    plt.plot(wavelength, convolve(flux, Gaussian1DKernel(5)), color='k', label='Smoothed spectrum')
    
    # Overplot the model spectrum in red
    plt.plot(wavelength, model, color='r', label='Model spectrum')
    
    plt.legend()
    plt.show()

Reorder spectrum records¶

The ordering of the results of client.retrieve() is not necessarily sorted to match the order of the IDs passed to the method. The reorder() method will reorder a Retrieved object's results to match the original ID order. However, it is only available when client.retrieve() is called without a fmt argument. When fmt='specutils' or fmt='pandas' is specified, the return value is a specutils object or a Pandas DataFrame rather than a Retrieved object, and reorder() cannot be applied.

If you need to preserve ordering when working with specutils or Pandas objects:

  1. Call client.retrieve() without setting fmt to obtain raw records
  2. Apply reorder() to align the results with the input ID order
  3. Convert the reordered records using to_specutils() or to_pandas()

Appendix C: Working with units from the SPARCL response header¶

SPARCL returns unit metadata alongside each Retrieved or Found result. The method unit_for() can be used to give you access to unit information.

The returned string is always compatible with astropy.units.Unit(), so you can attach it to a NumPy array directly. If no data_release is provided and the units for fieldname differ across the available data releases, a dict is returned mapping each data release name to its unit string.
